# 排版规范细则（字号/配色/边框）

SKILL.md 是速查表与流程，本文是参数依据与逐区块配色表。

## 一、字号与行距

| 字号 | 适用 |
|---|---|
| 14px | 精致/文艺类 |
| 15px | 万能默认，拿不准就用 |
| **16px** | **资讯科普类长文（本号定版）** |

字体用后台默认（微软雅黑/苹方），不可换，一篇文章不超过两种。

| 项 | 值 | 说明 |
|---|---|---|
| 行距 | **1.75** | 全篇统一，不逐段调 |
| 段间距 | 22px margin-bottom | 无首行缩进 |
| 字间距 | 0.5px / 1px | 干货短稿 0.5，长技术文 1，上限 2px |
| 两端边距 | 10px | section padding |

## 二、色板

### 主色

| 角色 | 字色 | 边条色 | 用途 |
|---|---|---|---|
| 正文 | `#3F3F3F` | — | 所有段落 |
| 小标题蓝 | `#2B77BF` | 左 4px `#2B77BF` | h2、表头、结构标识 |
| 分层绿 | `#046B27` | 左 4px `#09B83E` | 分层、文末绿卡 |
| 强调红 | `#A8281A` | 左 4px `#D93F2B` | 金句、警示，全文 1-2 处 |
| 场景橙 | `#8A5A0B` | 左 4px `#E8A33D` | 场景标签，3 处以内 |

### 浅底与辅助色

| 用途 | 色值 |
|---|---|
| 绿系浅底 / 蓝系浅底 / 红系浅底 / 橙系浅底 | `#F0F9F2` / `#F4F8FC` / `#FDF3F2` / `#FFF8EC` |
| 中性浅底（数据表隔行） | `#F7F9FA` |
| 边框灰 / 注释灰 | `#E3E8EF` / `#7C8798` |
| 代码底 / 代码字 | `#282C34` / `#E4E6EB` |

### 三色分工（红线）

**红 = 强调与提醒 · 绿 = 分层与收尾 · 蓝 = 结构与规格。**

| 版式 | 正确底色 | ⛔ 常见错法 |
|---|---|---|
| 金句 / 强调 | **`#FDF3F2` 红** | 误用绿底/蓝底 |
| 警示 / 封面警示卡 | `#FDF3F2` 红 | 2px 边框写成 1px |
| 升华 / 收尾 | **`#F0F9F2` 绿** | 误用红底/蓝底 |
| 分层 / 报头 / 文末引导 | `#F0F9F2` 绿 | 误用蓝底 |
| 导语 / 规格 | `#F4F8FC` 浅蓝 | 误用绿底 |
| 导语（正文） | **蓝色 `#2B77BF`** | 写成深灰 |

其他规则：提示词/代码/命令行一律 CLI 黑底；表格归蓝色系；红色仅用于提醒类语义，越少越有力。绿+蓝双主色是实测定版，不要改成单色方案。

## 三、逐区块配色（整套照配，不拆开挑用）

| 区块 | 底色 | 文字 | 边框 |
|---|---|---|---|
| 底板 | `#F2F3F5` | — | 无（合法例外） |
| 报头 | `#F0F9F2` | 标题 `#046B27` | **2px** `#09B83E` |
| 导语 | `#F4F8FC` | **正文 `#2B77BF`** | 无（刻意） |
| 栏目标 | `#FFFFFF` | `#046B27`，序号 `#09B83E` | 1px，20px 胶囊 |
| 白卡（论述/资讯） | `#FFFFFF` | 标题 `#2B77BF` | 1px `#E3E8EF` |
| 绿卡（分层） | `#F0F9F2` | 标题 `#046B27` | 1px + 左 4px 绿 |
| 红卡（金句） | **`#FDF3F2`** | `#A8281A` | 1px + 左 4px 红 |
| 蓝卡（规格） | `#F4F8FC` | 标题 `#2B77BF` | 1px |
| 提醒卡 | `#FDF3F2` | `#A8281A` | 1px |
| 升华 | `#F0F9F2` | `#046B27` | 1px，18px 居中 |
| 事实来源 | `#FFFFFF` | 标题 `#2B77BF` | 1px（内容级） |
| 文末①最值得深挖 | `#FDF3F2` | `#A8281A` | **2px** `#D93F2B` |
| 文末③开源仓库 | `#F0F9F2` | `#046B27` | **2px** `#09B83E` |
| 文末④AI 对话 | `#F0F9F2` | `#046B27` | **2px** `#09B83E`，全篇最后一块 |
| 代码块 | `#282C34` | `#E4E6EB` | 无（合法例外） |
| 数据表 | 表头 `#2B77BF` | `#FFFFFF` | 外框 `#E3E8EF`，6px 圆角 |

**配额**：红底 ≤500字→1 · ≤1000字→2 · ≤2000字→3 · >2000字→4；卡片数 = 字数 ÷ 150，最少 2 张。

**悬浮形态**：圆角 12px + 阴影 `0 2px 10px rgba(31,45,61,0.08)` + 内边距 18/20px。数据表与代码块不是这个形态。

## 四、边框三档

| 档 | 值 | 用在 |
|---|---|---|
| 2px 亮绿 | `border: 2px solid #09B83E` | 封面级（报头/文末引导卡） |
| 2px 红 | `border: 2px solid #D93F2B` | 文末① |
| 1px 浅灰 | `border: 1px solid #E3E8EF` | 正文内容区块 |

**铁律：有 `background` 的 section 必须有整圈 `border`，按结构判，不按内容数卡片。**

合法例外（无边框）：导读块（按内容语义豁免，不按底色——`#F4F8FC` 规格卡必须有边框）· 底板 · 代码块 · 数据表 · 章节条 · 场景标 · 分隔点。

## 五、微信 HTML 硬约束

| 约束 | 原因 |
|---|---|
| 样式全部内联 `style="..."` | 微信过滤 `<style>` 标签 |
| 不用 class | 微信不保留 |
| 不用 `<script>`/`onclick` | 安全策略 |
| 标签配对且嵌套正确 | 错位渲染错乱 |
| 图片仅 `mmbiz.qpic.cn` | 外图先传素材库 |
| 外链仅 `mp.weixin.qq.com` | 其他域名可能被拦；短链被改写成 `?__biz=...` 长链属正常 |

## 六、封面图

- 比例 2.35:1（900×383），JPEG q92
- AI 生成图带水印，用 Pillow 裁掉底部约 8%，小幅度试裁
- 主体偏左时，生成 prompt 加「画面完全居中构图，左右留白均衡」

```python
from PIL import Image
im = Image.open(src).convert('RGB')
W, H = im.size
im2 = im.crop((0, int(H*0.03), W, int(H*0.92)))
im2 = im2.resize((900, 383), Image.LANCZOS)
im2.save('cover_900x383.jpg', 'JPEG', quality=92, optimize=True)
```

## 七、换品牌色

只改两处：小标题色换品牌主色；强调色选补色（对比度 ≥3:1）。代码黑 `#282C34` 不变；浅底与边框灰随主色同步更新。
